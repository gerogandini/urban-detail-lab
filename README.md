# 🚗 Urban Detail Lab

Página web de **Urban Detail Lab**, un emprendimiento de lavado y estética automotriz.

El sitio permite a los clientes seleccionar una fecha y horario, completar sus datos y enviar una solicitud de turno directamente por WhatsApp.

## ✨ Características

- Diseño responsive para celular, tablet y computadora.
- Estética basada en la identidad visual del logo.
- Paleta de colores negro, blanco y verde brillante.
- Selector de fecha.
- Horarios de atención de **08:00 a 18:00**.
- Atención de **lunes a domingos**.
- Selección de servicio.
- Datos del vehículo y contacto del cliente.
- Confirmación de la solicitud mediante WhatsApp.

## 📅 Horarios

Los turnos están disponibles todos los días entre **08:00 y 18:00**.

```text
08:00 · 09:00 · 10:00 · 11:00
12:00 · 13:00 · 14:00 · 15:00
16:00 · 17:00 · 18:00
```

> Actualmente la página envía la solicitud por WhatsApp, pero no guarda los turnos en una base de datos ni bloquea automáticamente horarios ya reservados.

## 📲 Cómo funciona

1. El cliente ingresa su nombre.
2. Ingresa su teléfono.
3. Selecciona una fecha.
4. Elige el servicio.
5. Indica su vehículo.
6. Selecciona un horario.
7. Presiona **Confirmar por WhatsApp**.
8. WhatsApp se abre con los datos de la reserva preparados.

La confirmación definitiva queda a cargo de Urban Detail Lab.

## 🚀 GitHub Pages

Para publicar el proyecto desde GitHub:

**Settings → Pages → Build and deployment**

Seleccionar:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

GitHub Pages publicará automáticamente el contenido de `index.html`.
